Why this exists

This isn't a hunch — five independent findings led here

n=6,000+

An analysis of over 6,000 real n8n workflows named silent mid-workflow failures as a recurring pattern: the run stops or misbehaves while still reporting success.

n8n forum

Open community threads describe Cloudflare HTTP 520 interrupting workflows mid-run — an external dependency breaking in a way n8n's own error handling doesn't catch.

Zapier

The identical disease is documented independently for Zapier, described as "a green checkmark that ran perfectly and did exactly the wrong thing" — this spans the category, not one tool.

NotiLens

Four ways to check

Verify the outcome, not just the absence of an error

Field Exists

Fails if an expected field is missing, null, or blank.

Field Equals

Fails if a field doesn't match the value you expected.

Hidden Error Scan

Scans a response body for failure indicators, even under an HTTP 200.

Independent Re-Check

Calls a second API afterward to confirm the record actually exists.
